## High Risk Regions

Users and businesses from high risk regions can be onboarded with additional compliance measures, including liveness checks and phone verification. Support for these user types may vary depending on the region.

| Country | ISO Code | Business | Individual |
| :-- | :-- | --- | --- |
| Bolivia | BOL | Yes | No |
| India | IND | Yes | No |
| Nigeria | NGA | Yes | No |
| Panama | PAN | Yes | No |
| Philippines | PHL | Yes | No |
| Saudi Arabia | SAU | Yes | No |
| Vietnam | VNM | Yes | No |

<Info>
  See [Liveness Checks](/compliance/liveness-checks) for ownership thresholds and the [Liveness Checks guide](/guides/liveness-checks) for the integration flow.
</Info>
